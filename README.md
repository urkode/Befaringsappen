# Befaringsskisse

En mobil-first webapp for befaring: ta bilde, tegn/legg til tekst og del den ferdige pdf-skissen.

## Slik brukes den

1. Trykk på **Åpne kamera** eller velg et eksisterende bilde.
2. Tegn med pennen. Velg **T** for plassert, redigerbar tekst.
4. Velg **Ferdig** og del pdf-filen eller send den på Mail. Tegne/tekst-grunnlag kan enkelt fjernes i etterkant.
